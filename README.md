# Python for DevOps 🤖

A hands-on DevOps project combining **Python automation with an AI-powered DevOps Agent**.

## 🚀 Features

* System & CPU monitoring
* Log file analysis
* Docker container monitoring
* DevOps automation using Python
* AI-powered assistance using **LangChain + Ollama**
* Local LLM integration with **Llama 3.2**

## 🛠️ Tech Stack

* Python
* LangChain
* Ollama
* Llama 3.2
* Docker
* Linux / Bash
* Git & GitHub

## 🤖 AI DevOps Agent

The project uses a local **Llama 3.2** model through Ollama and LangChain to interact with DevOps tools such as:

* Reading log files
* Counting log levels
* Checking Docker containers

## 🎯 Purpose

To learn and build practical **DevOps automation and AI-assisted infrastructure tools** using Python.
